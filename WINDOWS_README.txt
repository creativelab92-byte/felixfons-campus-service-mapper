FELIX FONS CAMPUS SERVICE MAPPER — WINDOWS
Версия 0.3.0, 26 октября 2026 года

Для чего нужен архив

Локально составляет предварительную карту одного компьютера Windows:
версия ОС и сборка, IIS-сайты и их привязки, TCP-порты, службы,
установленные приложения из реестра, номера установленных обновлений,
состояние профилей брандмауэра, локальные сертификаты и количество ошибок
в системном журнале за сутки. Для каждого IIS-сайта создаёт список ручных
проверок перед включением. Один запуск показывает только один компьютер.

Требования

- Основные целевые системы: Windows 10 Enterprise LTSC 2021 (21H2,
  сборка 19044) и Windows Server 2008 R2. На Windows Server 2008 SP2
  запуск возможен при установленном PowerShell 2.0, но не проверен.
  Совместимость с каждым более новым выпуском Windows также не подтверждена.
- Windows PowerShell 2.0 или новее. На Server 2008 R2 версия 2.0 входит
  в систему; на Server 2008 SP2 её может потребоваться установить отдельно.
  Узнать версию: $PSVersionTable.PSVersion
- Доступ к самому компьютеру. Для полной карты желательно открыть консоль
  от имени локального администратора. Скрипт сам права не повышает.
- Разрешение организации на запуск локального .ps1. Скрипт не меняет
  системную политику исполнения и не обходит ограничения.
- Папка, где можно создать каталог отчёта; ориентир — 20 МБ.
  Если ужесточить права на каталог не получится, данные всё равно будут
  записаны, а в summary.txt появится предупреждение. Проверьте доступ
  к этой папке перед передачей отчёта внутри организации.
- Python, интернет и сторонние модули на обследуемом Windows не нужны.

Порядок работы на каждом компьютере

1. Распакуйте архив в отдельную папку.
2. Откройте Windows PowerShell в соответствии с внутренним регламентом.
3. Перейдите в папку с windows_mapper.ps1.
4. Выполните: .\windows_mapper.ps1
5. Получите папку campus-report-ГГГГММДД-ЧЧММСС внутри личной папки
   %LOCALAPPDATA%\FelixFonsCampusMapper. Путь также появится в консоли.
   Чтобы выбрать место: .\windows_mapper.ps1 -OutDir C:\Private\campus-report-01
6. Откройте summary.txt и service_cards.txt. Каталог отчёта не отправляйте
   наружу и не публикуйте на GitHub.

Если исполнение .ps1 запрещено политикой организации, администратор должен
разрешить конкретный запуск утверждённым способом. Не отключайте защиту
всей системы ради утилиты.

Файлы результата

summary.txt             Короткая карта узла и вопросы для администратора.
service_cards.txt       Проверки по каждому найденному IIS-сайту.
inventory.private.json  Закрытые технические сведения для объединения узлов.
manifest.sha256         Контрольные суммы этих трёх файлов.

Для объединения с Linux-отчётами скопируйте закрытые JSON-файлы в
изолированную папку на компьютере аналитика с Python 3.8+ и запустите:

python campus_mapper.py merge windows.json linux.json --out combined

Python нужен только на компьютере, где объединяют отчёты. Windows-отчёт
содержит внутренние IP и названия служб; храните его внутри университета.

Что означают предупреждения

Запись о программе в реестре не доказывает, что сайт использует именно её.
Слушающий порт не доказывает доступ из интернета. Отсутствие IIS-сайта не
исключает другого веб-сервера. Номер обновления не доказывает полноту патчей.
Внешние маршруты, роли пользователей, исходный код, БД, работу входа, права
на резервную копию и пробное восстановление этот сборщик не проверяет.

Windows Server 2008 и 2008 R2 сняты с поддержки Microsoft. Утилита помечает это
отдельно и не может заменить миграцию либо решение о временной изоляции.
Windows 10 LTSC 21H2 с указанной сборкой 19044.4651 требует сверки
обновлений: опубликованная октябрьская сборка 2026 года выше. Точный набор
недостающих исправлений устанавливается отдельно по каналу обновлений.

Самопроверка без сбора данных: .\windows_mapper.ps1 -SelfTest
