ИЗМЕНЕНИЯ FELIX FONS CAMPUS SERVICE MAPPER

Версия 0.3.0 — 26.10.2026

- Добавлен автономный сборщик для Windows на PowerShell 2.0+ с отдельной
  инструкцией TXT. Он составляет локальную карту ОС, служб, портов, IIS-сайтов,
  выбранных приложений, номеров обновлений, сертификатов и ошибок журналов.
- Диагностические данные записываются даже при ошибке ограничения прав на
  каталог; отчёт содержит предупреждение об унаследованных правах.
- Добавлены предварительные признаки риска для Windows Server 2008/2008 R2,
  устаревшей сборки Windows 10 LTSC и портов данных на всех интерфейсах.
- Объединитель отчётов учитывает IIS-сайты Windows наряду с Linux-сайтами.
- Проверено на Windows PowerShell 5.1; Server 2008/2008 R2 остаются без
  фактического прогона и требуют проверки на целевых машинах.

Версия 0.2.0 — 25.10.2026

- Отдельные офлайн-подсказки по CVE-2026-15176, CVE-2026-93479 и
  CVE-2026-97205 с верными диапазонами upstream-версий nginx.
- Признаки директив alias/rewrite/$request_filename, map/regex/capture,
  AIO/SSI собираются как булевы значения без копирования конфигурации.
- При недоступной CLI-версии nginx используется номер установленного пакета
  с явной пометкой о происхождении сведений.
- Считывается состояние ASLR по локальному параметру Linux, если доступно.
- Обновлены ссылки на первичные бюллетени и пояснение об ограничениях вывода.
- Добавлены проверки диапазонов версий, неразглашения значений конфигурации
  и резервного источника сведений о версии.

Эти подсказки не подтверждают наличие уязвимости в работающем сервисе и не
заменяют сверку патча поставщика ОС и конфигурации конкретного маршрута.

Версия 0.1.0 — 25.10.2026

- Первый публичный выпуск автономной карты Linux-сервисов.
