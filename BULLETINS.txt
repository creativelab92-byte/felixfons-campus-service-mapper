ОФИЦИАЛЬНЫЕ БЮЛЛЕТЕНИ: СНИМОК ПРАВИЛ НА 25.10.2026

Этот файл объясняет только встроенные подсказки утилиты. Правила работают
офлайн и не обновляются сами. Вывод «проверка» означает, что администратору
нужно сопоставить наблюдение с работающим процессом, настройками и бюллетенем
поставщика ОС. Это не подтверждение уязвимости конкретного сайта.

PHP
Официальная публикация 21.10.2026: выпуски 8.2.35, 8.3.36, 8.4.27 и
8.5.12 исправляют две критические ошибки. Публикация 23.10.2026 отдельно
рекомендует временно установить session.upload_progress.enabled=0 для
необычного сочетания настроек и кода. Утилита видит номер PHP CLI, часть
конфигурации PHP-FPM и метку образа. Версию работающего веб-обработчика надо
подтвердить отдельно. Старый номер дистрибутивного пакета может содержать
исправление, перенесённое поставщиком ОС.
Источник: https://www.php.net/archive/2026.php

NODE.JS
Публикация 21.10.2026: выпуски 22.23.4, 24.22.1 и 26.12.1 закрывают
ошибки безопасности. Утилита сравнивает эти пороги с Node CLI или полной
меткой стандартного контейнерного образа. Это не версия каждого запущенного
приложения; её следует установить на конкретном сервисе.
Источник: https://nodejs.org/en/blog/vulnerability/october-2026-security-releases

NGINX
В таблице проекта указаны исправленные ветки 1.30.6+ и 1.31.7+ для
новейших на дату снимка пунктов. Утилита помечает более ранние признаки
версии для проверки. Применимость зависит от использованных модулей и
директив, а пакет поставщика ОС может иметь отдельное исправление.
Источник: https://nginx.org/en/security_advisories.html

APACHE HTTP SERVER
Выпуск 2.4.69 от 01.10.2026 включает исправления опубликованных ошибок.
Утилита отмечает наблюдаемую версию 2.4 ниже 2.4.69 как повод сверить
модули, версию работающего процесса и исправления поставщика ОС.
Источник: https://httpd.apache.org/security/vulnerabilities_24.html

ПАКЕТЫ ОПЕРАЦИОННОЙ СИСТЕМЫ
Сверяйте номер установленного пакета с бюллетенями вашего дистрибутива.
Сравнение только с номером версии исходного проекта может ошибаться, когда
поставщик ОС перенёс исправление в пакет со старым номером upstream.
Ubuntu: https://ubuntu.com/security/notices
Debian: https://www.debian.org/security/
Red Hat: https://access.redhat.com/security/security-updates/security-advisories

Другие продукты и ошибки этим снимком автоматически не оцениваются. Если
прошло больше семи дней с 25.10.2026, отчёт отдельно напомнит проверить
новые публикации перед принятием решения.
