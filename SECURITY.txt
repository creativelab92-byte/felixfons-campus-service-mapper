БЕЗОПАСНОЕ ИСПОЛЬЗОВАНИЕ И ОБРАТНАЯ СВЯЗЬ

Запускайте утилиту только на серверах, за обследование которых вы отвечаете.
Перед первым запуском прочитайте исходный код и README.txt. Утилита не требует
сетевого доступа; для анализа в изолированном контуре интернет не нужен.

Каждый созданный отчёт остаётся внутри университета и используется его
уполномоченными сотрудниками. Не публикуйте отчёты в GitHub Issues,
публичных чатах и открытых облачных папках. Публичный репозиторий содержит
только исходный код и учебные примеры, а не результаты обследования вузов.

Если найдена ошибка в самом коде, можно создать GitHub Issue с вымышленным
примером после публикации репозитория. По вопросам работы утилиты обратитесь
к Felix Fons через https://felixfons.ru либо по телефону +7 917 410-87-48.
Не прикладывайте к обращению отчёты университета, пароли и ключи.

Наблюдение в отчёте — повод для проверки администратором, а не доказательство
компрометации и не основание автоматически включать или отключать систему.
